## 1. 🎯 OBJETIVO GENERAL DEL PROYECTO

Crear un bot de WhatsApp que:

- Reciba mensajes de finanzas personales tipo `"comida menu 12"`.
- Los registre automáticamente en **Google Sheets compartido** con la pareja.
- Responda con confirmación.
- Permita identificar quién registró cada gasto (**Daniel** o **Leslye**).
- Redirija a cualquier número no autorizado hacia el WhatsApp personal de Daniel y lo registre en una hoja separada.
- Funcione 24/7 sin depender de la computadora local.

## 6. 🧠 LÓGICA ACTUAL DE SCRIPTS

### `config/settings.py`
- Carga variables de entorno con `python-dotenv`.
- Define:
  - `WHATSAPP_PHONE_NUMBER_ID`
  - `WHATSAPP_ACCESS_TOKEN`
  - `WHATSAPP_VERIFY_TOKEN`
  - `WHATSAPP_API_VERSION`
  - `WHATSAPP_API_URL = f"https://graph.facebook.com/{WHATSAPP_API_VERSION}/{WHATSAPP_PHONE_NUMBER_ID}/messages"`
  - `SPREADSHEET_ID`
  - `GOOGLE_CREDENTIALS = 'config/google-credentials.json'` (ruta local; en Render se resuelve con `project_dir`)

### `src/app.py`
- Ruta `/webhook` GET: verificación del webhook (`hub.mode`, `hub.verify_token`, `hub.challenge`).
- Ruta `/webhook` POST: recibe `data`, recorre `entry → changes → value → messages`, extrae `from_phone` y `text`, y llama a `handler.process_message(from_phone, text)`.
- Retorna `ok`, 200.

### `src/parser.py`
- Función: `parse_message(message, from_phone=None)`
- Parsea:
  - `partes[0]` → categoría
  - `partes[1:-1]` → descripción
  - `partes[-1]` → monto (float)
- Fecha automática en hora peruana:
  - `datetime.now(timezone.utc) - timedelta(hours=5)`
  - Formato: `%d/%m/%Y %H:%M`
- Tipo:
  - Categorías de ingreso: `salario`, `sueldo`, `cobro`, `venta`, `ingreso` → `Ingreso`
  - Lo demás → `Egreso`
- Persona:
  - `"51986981127"` → Daniel
  - `"519XXXXXXX"` → Leslye (⚠️ debe reemplazarse por su número real)
  - Otro → Desconocido
- Retorna `None` si no puede parsear.

### `src/sheets_service.py`
- Clase `GoogleSheetsService`
- Autenticación con cuenta de servicio.
- `append_expense(fecha, categoria, descripcion, monto, tipo, persona)`:
  - Escribe en `range='A:F'`
  - Columnas: A Fecha, B Categoría, C Descripción, D Monto, E Tipo, F Persona.
- `append_client(phone, message)`:
  - Escribe en `range='Clientas!A:C'`
  - Columnas: A Fecha, B Teléfono, C Mensaje.
  - Fecha en hora peruana.

### `src/message_handler.py`
- Lista `NUMEROS_AUTORIZADOS`:
  - `"51986981127"` (Daniel)
  - `"519XXXXXXX"` (Leslye, pendiente de actualizar)
- Lógica de seguridad:
  - Si `from_phone` NO está autorizado:
    - Llama a `append_client(from_phone, message)`.
    - Envía mensaje de redirección:
      ```
      Hola 👋 Este número ya no tiene atención por WhatsApp.
      Para cualquier consulta, escríbeme a mi número personal:
      📱 +51 986 981 127 (Daniel)
      ¡Gracias!
      ```
    - Retorna.
- Comando `/ayuda`:
  - Muestra instrucciones de uso.
- Parseo y guardado:
  - Llama a `parse_message(message, from_phone)`.
  - Si hay datos, llama a `append_expense(...)`.
  - Envía confirmación:
    ```
    ✅ {tipo} registrado por {persona}:
    📌 {categoria}: {descripcion}
    💰 S/ {monto:.2f}
    📅 {fecha}
    ```
- Si no entiende, envía mensaje de ayuda.

### `src/whatsapp_service.py`
- Clase `WhatsAppService`
- `send_message(to_phone, message)`:
  - POST a `WHATSAPP_API_URL`.
  - Encabezados: `Authorization: Bearer {access_token}`, `Content-Type: application/json`.
